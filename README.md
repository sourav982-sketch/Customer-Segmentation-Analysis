# Customer Segmentation Analysis

## 📌 Project Overview

This project focuses on analyzing customer behavior and demographics to identify meaningful customer segments.

The project uses **Python, K-Means Clustering, and Power BI** to understand customer purchasing patterns and preferences.

## 🎯 Objectives

- Segment customers based on their behavior and demographics.
- Identify different customer groups using clustering.
- Analyze purchasing patterns and customer preferences.
- Visualize customer segments using an interactive Power BI dashboard.
- Generate useful business insights from customer data.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- K-Means Clustering
- Power BI
- Microsoft Excel
- GitHub

## 📊 Features Used for Clustering

The K-Means clustering model uses:

- Annual Income
- Purchase Frequency
- Average Order Value
- Total Spend
- Website Visits

The numerical features were standardized before applying K-Means clustering.

## 📈 Power BI Dashboard

The dashboard includes:

- Customer Segment Distribution
- Income vs Total Spend Analysis
- Purchase Frequency by Segment
- Total Spend by Segment
- Customer demographics
- Category preferences
- Interactive slicers for filtering the analysis
